VRChat Room Monitor  v{VERSION}
==============================

■ これは何？
VRChat のログを読み取って、今いるルームの状況と入退室の記録をデスクトップに表示するアプリです。
VR ゴーグルを外してデスクトップで作業している間に誰かが入ってきても、
画面右下のポップアップと通知音で気づけます。

■ 使い方
1. zip を展開し、VRChatRoomMonitor.exe をダブルクリックします（インストールは不要です）。
2. VRChat を起動中なら、すぐに現在のルームが表示されます。
   VRChat より先に起動しておいても構いません。VRChat を再起動しても自動で追従します。

初回起動時に「Windows によって PC が保護されました」と表示された場合は、
「詳細情報」→「実行」を押してください。
電子署名の無いアプリを初めて開くときに表示される Windows の確認画面です。

ウィンドウを閉じてもトレイ（タスクバー右下）で監視を続けます。
もう一度開くときはトレイのアイコンをクリックし、終了するときは右クリックして「終了」を選びます。

■ 画面の見かた
・上部        ワールド名、インスタンスの種類（Public / Friends+ / Invite など）、
              リージョン、インスタンス番号、入室時刻と経過時間
・ルーム内    いまいる人の一覧。後から来た人は 2 分間緑色で表示します。
              自分が入室した時点で既にいた人は「先客」と表示します。
・入退室ログ  入室・退室・ワールド移動・招待／招待リクエスト（新しいものが上）
・下部        常に最前面 / ポップアップ / 通知音 / 退室も通知 / SteamVR と同時に起動 の切り替え

通知が出るのは、自分が入室した後に来た人と、届いた招待です。
入室した時点で既にいた人については通知しません。

■ 履歴の保持
入退室の履歴はメモリ上にだけ持ち、履歴のファイルは作りません。
起動時に VRChat の最新のログファイル 1 つから履歴を作り、起動中は最大 500 件まで追加します。
アプリを終了すると消え、次の起動時に最新のログファイルから作り直します。

■ SteamVR と同時に起動する
このアプリを起動した状態で SteamVR を起動すると、SteamVR の
「設定」→「起動/シャットダウン」→「起動時のオーバーレイアプリを選択」の一覧に自動で追加されます。
追加されるだけで、同時に起動するようにはなりません。

同時に起動したいときは、一覧でオンにするか、このアプリの「SteamVR と同時に起動」にチェックを入れます。
SteamVR から起動された場合は、SteamVR を終了すると一緒に終了します。
exe を移動した場合は、移動先で一度起動すると SteamVR の登録も新しい場所に更新されます。

なお、SteamVR の設定の「アドオン」はドライバ（機器を動かすプログラム）の一覧なので、
このアプリは表示されません。

■ 更新
新しい版があると、画面上部とポップアップで知らせます。
インストーラ版は「更新して再起動」を押すだけで更新できます。
exe 版は「配布ページを開く」から新しい版をダウンロードしてください。

■ 動作環境
・Windows 10 / 11（64bit）
・Microsoft Edge WebView2 ランタイム（Windows 11 には標準で入っています。
  画面が表示されない場合はインストーラ版をお使いください。必要に応じて自動で入ります）
・PC 版 VRChat（Steam 版、Meta Quest Link や Steam Link で PC につないで遊ぶ場合も含む）
  ※ Quest 単体（PC を使わない遊び方）では PC にログが出ないため使えません。

■ 安全性について
・VRChat が PC に書き出すログファイル
  （%USERPROFILE%\AppData\LocalLow\VRChat\VRChat\output_log_*.txt）を読むだけです。
・VRChat 本体の改変、VRChat アカウントへのログインは行いません。
・インターネット通信は、新しい版の確認と更新のダウンロード（GitHub）だけです。
  画面下の「更新を確認」をオフにすると通信しません。
・ログにはフレンドの情報が含まれないため、フレンドかどうかの判別や
  オンライン中のフレンド数の表示はできません。
・SteamVR の設定を変更するのは、上記の一覧への追加と同時起動の切り替えのときだけです。

■ 設定とアンインストール
設定は %APPDATA%\com.ryoctrl.vrchatroommonitor に保存されます。
不要になったら、画面下の「SteamVR の一覧から削除」を押してからアプリを終了し、
VRChatRoomMonitor.exe と上記のフォルダを削除してください。
